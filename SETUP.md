## 0. Что это и из чего состоит

Гейм-приложение для Coca-Cola: покупаешь напиток → вводишь код с крышки →
получаешь монеты → одеваешь своего белого медведя → вызываешь друзей на баттл
образов → подписчики голосуют (голос = 1 монета в призовой фонд) → победитель
забирает фонд и растит серию побед.

```
Telegram Bot ──уведомления──┐
                            ▼
Telegram Mini App / PWA ──HTTP──► FastAPI ──► PostgreSQL
Админ-панель ─────────────HTTP──►
```

Четыре контейнера, все в одном compose-проекте `cci`:

| контейнер | что делает |
|---|---|
| `cci-postgres` | база; наружу не торчит вообще |
| `cci-api` | REST API + отдаёт мини-апп и админку + миграции при старте |
| `cci-worker` | бот, доставка уведомлений, завершение баттлов, напоминания |
| `cci-tunnel` | Cloudflare Tunnel — единственный вход снаружи |

Адреса внутри одного домена:

| путь | что |
|---|---|
| `/app/` | мини-апп (он же PWA) — **этот URL идёт в BotFather** |
| `/admin-ui/` | админ-панель |
| `/docs` | Swagger по всему API |
| `/health` | живо ли приложение |
| `/health/db` | жива ли база |
| `/media/...` | картинки одежды и аватара |

### 2.5. Языки

Приложение и бот говорят на русском, английском и азербайджанском.

Как выбирается язык: сначала то, что сохранено у аккаунта, потом язык
Telegram-клиента, потом русский. Язык из Telegram записывается при первом
входе и больше не перезаписывается — выбор, сделанный в приложении, не должен
сбрасываться при следующем входе.

Переключатель — **Профиль → Язык**, три кнопки `Русский · English ·
Azərbaycan` под аватаром и счётчиками. Только на своём профиле: на чужом там
кнопка «Подписаться». Он же меняет язык бота, потому что уведомления
собираются на сервере, а не в приложении.

Где лежат строки:

| файл | что |
|---|---|
| `miniapp/src/i18n/{ru,en,az}.js` | интерфейс, 147 ключей |
| `app/services/i18n.py` | уведомления и сообщения бота |

Русский — эталон: недостающий в другом языке ключ подставляется из него.

После правки словарей обязательно:

```bash
node scripts/check_translations.mjs
```

Падает, если ключи или плейсхолдеры разошлись. Без этой проверки пропуск не
виден — он молча подменяется русским.

Добавить четвёртый язык: новый файл в `miniapp/src/i18n/`, добавить его в
`TABLES` и `LANGUAGES` в `index.jsx`, новый словарь в `TRANSLATIONS` в
`app/services/i18n.py`, код языка в `SUPPORTED_LANGUAGES` там же и в
`Literal` в `app/schemas/user.py`.

Названия вещей («Cola Classic Tee») намеренно не переводятся — это имена
предметов, они одинаковы во всех языках. Вкладки магазина и гардероба
группируются по слотам аватара и переводятся.

### 2.6. Перерисовать одежду

Вся одежда — сгенерированные SVG. Правишь числа в скрипте, перегенеришь:

```bash
.venv/Scripts/python.exe scripts/generate_assets.py
```

Важное правило: **все слои рисуются в одной системе координат**
`viewBox="0 0 512 768"`. Поэтому аватар собирается простым наложением файлов
друг на друга, без единой строчки выравнивания. Новый предмет должен попадать
в «якорную зону» своего слота — они перечислены в шапке
`scripts/generate_assets.py`.

Заменить конкретную вещь на нормальную дизайнерскую картинку можно и без
деплоя — через админку, полем `image_url`.

## 4. Домен и Cloudflare Tunnel

### Почему туннель, а не nginx

На сервере уже живут два чужих проекта: порт **80** держит nginx-контейнер
link2do, порт **443** — Caddy от stride. Чтобы повесить свой `server_name`,
пришлось бы править чужой прод.

Cloudflare Tunnel это обходит: `cloudflared` соединяется **изнутри наружу**,
портов на хосте не занимает вообще, HTTPS и сертификат даёт Cloudflare.
Telegram Mini App без HTTPS не работает, так что это ещё и решает вопрос
сертификата.

### Что уже сделано

Зона `koblab.az` уже была в Cloudflare, поэтому NS никуда не переносились и
записи корня и `www` не трогались — добавился ровно один CNAME для `cci`.

Туннель **locally-managed**: креды лежат в `/opt/cci/cloudflared` на сервере,
а не в дашборде. Так сделано потому, что панель Zero Trust просит привязать
карту даже на бесплатном тарифе, а этот путь идёт через обычный логин
Cloudflare и стоит ноль.

Как это было создано (повторять не нужно, записано на случай переезда):

```bash
CFD="docker run --rm -v /opt/cci/cloudflared:/home/nonroot/.cloudflared cloudflare/cloudflared:latest"

# каталог должен принадлежать uid 65532 — образ работает не от root,
# иначе `login` не сможет записать свой cert.pem уже ПОСЛЕ клика в браузере
mkdir -p /opt/cci/cloudflared && chown -R 65532:65532 /opt/cci/cloudflared

$CFD tunnel login                          # печатает ссылку, один клик в браузере
$CFD tunnel create cci
$CFD tunnel route dns cci cci.koblab.az    # создаёт CNAME
cd /opt/cci && docker compose --profile tunnel up -d
```

### Сменить адрес

```bash
docker run --rm -v /opt/cci/cloudflared:/home/nonroot/.cloudflared   cloudflare/cloudflared:latest tunnel route dns cci новый.домен
nano /opt/cci/.env          # TELEGRAM_WEBAPP_URL=https://новый.домен/app/
cd /opt/cci && docker compose --profile tunnel up -d
```

И обновить URL в BotFather — иначе Telegram продолжит открывать старый.

### Одна настройка, которую стоит поменять руками

В Cloudflare → **Caching → Configuration → Browser Cache TTL** сейчас стоит
`4 hours`, и это значение перезаписывает наши заголовки для браузера. Видно
прямо сейчас:

```bash
curl -sI https://cci.koblab.az/app/       | grep -i cache-control  # no-cache, must-revalidate — прошло как есть
curl -sI https://cci.koblab.az/app/sw.js  | grep -i cache-control  # max-age=14400 — а вот это Cloudflare переписал
```

`index.html` Cloudflare считает динамикой и не трогает, а `sw.js` — статикой,
и подставляет свои четыре часа. Service worker решает, какую сборку видит
человек, поэтому именно его кэшировать нельзя: после деплоя телефон может до
четырёх часов работать по старому воркеру.

Поставь там **Respect Existing Headers**. Тогда каждый файл живёт ровно
столько, сколько сказало приложение:

| что | сколько кэшируется | почему |
|---|---|---|
| `/app/index.html`, `/app/sw.js` | не кэшируется, всегда перепроверка | index.html называет имя JS-бандла: закэшируешь его — и человек навсегда останется на той сборке, которую открыл первой |
| `/app/assets/index-<hash>.js` | год, `immutable` | имя содержит хэш сборки, новая версия — новое имя, старый файл не может оказаться неправильным |
| `/media/**` | час | одежда меняется редко, но не «никогда» |

На edge-кэш Cloudflare это не влияет — там всё и так правильно, статика
отдаётся с `Cf-Cache-Status: None`. Настройка касается только браузера
пользователя.

### Посмотреть без домена вообще

Быстрый туннель, без аккаунта и без токена:

```bash
cd /opt/cci && docker compose --profile preview up -d preview
docker compose logs preview | grep trycloudflare
```

Выключить: `docker compose stop preview && docker compose rm -f preview`

## 8. Коды для крышек

Один код = одно погашение = монеты. Хранится в таблице `qr_codes`.

Через админку: **QR Codes → Create**, там же выбирается продукт и номинал.

### Пачкой

```bash
docker exec cci-api python scripts/generate_codes.py --count 5000 --coins 50 --out /tmp/codes.csv
docker cp cci-api:/tmp/codes.csv /opt/cci/codes.csv
```

Все флаги: `--count`, `--coins`, `--product`, `--sku`, `--prefix`, `--out`.
Продукт ищется по SKU и создаётся, если его ещё нет, — то есть команду можно
гонять сколько угодно раз, второй продукт с тем же SKU не появится.

Скрипт, а не `INSERT ... md5(random())`, из-за алфавита. В кодах нет ни одной
пары символов, которые путают при наборе: **нет O и 0, нет I, L и 1, нет S и 5,
нет B и 8, нет Z и 2**. Код набирают руками с мокрой крышки, стоя в толпе, — и
`0` вместо `O` там стоит дороже, чем красивая однострочная команда. Плюс
разбивка по четыре символа: так код проверяют взглядом, не теряя места.

Уже выгруженное можно достать и из базы:

```bash
docker exec cci-postgres psql -U cci -d cci -A -F',' -c \
  "SELECT code, coin_value FROM qr_codes WHERE status = 'ACTIVE' ORDER BY created_at DESC" \
  > /opt/cci/codes.csv
```

### Тестовые коды, уже лежащие в боевой базе

20 по 50 монет — как настоящая крышка:

```
CF-MQ6K-T3FH   CF-EWNG-93FD   CF-WMXK-3KWX   CF-3VPF-RVC6   CF-3WVY-UEHR
CF-RDGC-3VYN   CF-CDHT-VJGP   CF-HFCP-HT44   CF-NEWH-EWEF   CF-NJ3A-VVE6
CF-YFVR-J3WD   CF-W4AC-T97P   CF-CVR4-4VUN   CF-HJAN-C7AD   CF-YJHF-E9M6
CF-XQ7R-PDKU   CF-GHF9-DR37   CF-CYQD-GNWX   CF-KWFY-UEQT   CF-YKK6-GY7D
```

5 по 500 монет — чтобы сразу что-то купить, не гася 18 крышек:

```
TEST-7736-V6GP   TEST-74KA-6YP4   TEST-ERGK-7E7D   TEST-UTJ6-YV9M   TEST-9PWX-VNKY
```

Перед фестивалем их стоит погасить или удалить:

```bash
docker exec cci-postgres psql -U cci -d cci -c \
  "DELETE FROM qr_codes WHERE code LIKE 'TEST-%' AND status = 'ACTIVE';"
```

### Что важно знать про коды

- Ввод **нечувствителен к регистру и пробелам**: `cf-mq6k t3fh` погасит
  `CF-MQ6K-T3FH`. Люди набирают их руками с крышки.
- Погасить можно ровно один раз. Второй раз — 409, даже если два человека
  жмут одновременно (строка блокируется на время транзакции).
- Один код = 50 монет = примерно треть дешёвой вещи в магазине. Самая дорогая
  вещь, Bear Paws за 900, — это 18 крышек, цель на весь фестиваль.

## 9. Каталог одежды через API

Одежду можно добавлять не только руками через админку. Есть эндпоинт, который
принимает вещь одним HTTP-запросом — имя, слот, цену и **сам рисунок SVG прямо
в теле запроса**. Сервер проверяет рисунок, кладёт его на диск, сам делает
миниатюру для витрины и заводит вещь в магазине.

Это сделано ради того, чтобы каталог мог наполнять кто-то, у кого есть только
HTTP: другая модель, фрилансер, скрипт. Ни доступа к серверу, ни аккаунта, ни
браузера не нужно.

```
GET    /catalog/spec              холст, слоты, якорные зоны, палитра, правила
GET    /catalog/items             что уже нарисовано
POST   /catalog/items             добавить вещь вместе с рисунком
PATCH  /catalog/items/{id}        перерисовать или поменять цену
DELETE /catalog/items/{id}        удалить, если её ещё никто не купил
```

Читать может кто угодно. Запись требует заголовка `X-Catalog-Key` с ключом из
`/opt/cci/.env` (`CATALOG_API_KEY`). Ключ уже сгенерирован и прописан. Сменить:

```bash
nano /opt/cci/.env          # CATALOG_API_KEY=новый
cd /opt/cci && docker compose up -d
```

Если ключ стереть, запись отключается совсем — эндпоинты отвечают 503, а не
пускают кого попало.

**Инструкция для того, кто рисует** — отдельный файл `CATALOG.md`: холст
512×768, якорная зона каждого слота, палитра, правила именования, ступени цен
и как проверить результат. Его можно отдать другому ИИ целиком.

Что проверяется на входе и отклоняется с понятным текстом: не тот `viewBox`,
`<script>`, атрибуты вроде `onload`, ссылки на чужие адреса, `<image>`,
`DOCTYPE` с сущностями, битый XML, файл больше 256 КБ. Файл кладётся на наш
домен и показывается всем игрокам, поэтому он не «чинится» молча, а
отклоняется — иначе вещь в магазине выглядела бы не так, как её рисовали.

Присланные вещи лежат в docker-томе `cci_media` (`/app/media/uploads` внутри
контейнера), а не в образе — иначе `docker compose up --build` стирал бы их
при каждом деплое. 24 вещи, которые идут в комплекте, лежат отдельно, в
образе, и никуда не деваются.

Купленную вещь удалить нельзя — человек заплатил за неё монеты. Ответ 409;
вместо удаления `PATCH` с `availability_status: "unavailable"` убирает её из
магазина, оставляя в гардеробах.

## 11. Если что-то не работает

| симптом | причина |
|---|---|
| мини-апп открывается, но всё 401 | токен в `.env` от другого бота, чем тот, где открыт Mini App |
| кнопка в боте не открывает приложение | URL не `https`, или не заканчивается на `/app/`, или в BotFather другой URL |
| бот молчит | `TELEGRAM_BOT_TOKEN` пуст → `docker compose logs worker` скажет «running without the bot» |
| уведомления не приходят | человек не нажимал `/start` у бота — Telegram запрещает писать первым. В базе они копятся и уйдут, как только он напишет |
| домен не отвечает | `docker compose logs tunnel`; проверь, что Public Hostname указывает на `api:8000`, а не на `localhost` |
| `/admin-ui/` даёт 404 | образ собран без фронта: `docker compose up -d --build` |
| сканер QR не открывается в браузере | в Safari нет `BarcodeDetector`. В Telegram работает всегда; в браузере — вводи код руками, поле всегда на экране |
| после деплоя старая версия | `docker compose up -d --build`, без `--build` пересборки не будет |
| контейнер собран заново, а в телефоне всё равно старое | кэш браузера, а не сервера. Проверь, что отдаёт сервер: `curl -sI https://cci.koblab.az/app/ \| grep -i cache` должно быть `no-cache`. Расцепиться на конкретном устройстве — открыть `https://cci.koblab.az/app/?fresh=1` один раз. Насовсем — Browser Cache TTL → Respect Existing Headers (раздел 4) |

Логи одной командой:

```bash
cd /opt/cci && docker compose logs -f --tail 50
```
